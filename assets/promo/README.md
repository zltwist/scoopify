# Scoopify Promo Templates

Template ini editable dalam format SVG:

- `poster-a3-scoopify.svg` - poster A3 portrait.
- `poster-a3-scoopify-canva-editable.pptx` - poster A3 editable untuk PowerPoint dan Canva.
- `spanduk-fix.pptx` - versi spanduk landscape dari `poster-fix.pptx`, ukuran 84.1 x 59.4 cm.
- `banner-booth-scoopify.svg` - spanduk booth horizontal.
- `feed-instagram-scoopify.svg` - feed Instagram 1:1.
- `story-instagram-scoopify.svg` - story Instagram 9:16.

Cara edit:

1. Buka file SVG di Figma, Illustrator, Inkscape, atau browser.
2. Ganti kotak `QR WEB` dengan QR web utama.
3. Ubah teks lokasi, tanggal, dan jam event sesuai kebutuhan.
4. Gambar produk memakai linked image dari `assets/menu/`, jadi bisa langsung diganti dengan PNG produk asli.
5. Font utama memakai `assets/font/LuckiestGuy-Regular.ttf`.

Untuk Canva:

1. Upload `poster-a3-scoopify-canva-editable.pptx` ke Canva.
2. Edit teks, shape, badge harga, panel rasa, dan QR placeholder dari Canva.
3. Export dari Canva sebagai `PDF Print` jika ingin dicetak.
