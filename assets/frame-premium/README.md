# Frame Premium Templates

Pakai file SVG template ini sebagai dasar desain frame premium. Area bergaris merah adalah area foto dari kamera, jadi jangan ditutup kalau ingin wajah tetap terlihat.

- `template-2-foto-3x4.svg`: kanvas `1080x1440`, output 2 foto.
- `template-3-foto-3x4.svg`: kanvas `1080x1440`, output 3 foto.
- `template-6-foto-9x13.svg`: kanvas `1080x1560`, output 6 foto.

Setelah desain selesai, export frame final sebagai PNG transparan dengan ukuran kanvas yang sama, lalu taruh di folder ini.
