# Frame Premium Scoopify

Taruh file frame premium di folder ini.

Rekomendasi format:
- PNG transparan.
- Rasio 9:16.
- Nama file sederhana, contoh: `bubble-pop.png`, `heart-wink.png`, `party-splash.png`.

Untuk sekarang frame masih digambar dari CSS/canvas. Setelah file PNG final tersedia, path frame bisa disambungkan ke sistem photobooth.
